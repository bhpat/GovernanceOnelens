# Glossary & References

## Glossary

| Term | Definition |
| --- | --- |
| **ABAC** | Attribute-based access control — access driven by attributes/tags on resources, users, and groups. |
| **Activity (monitoring lens)** | Governance-monitoring lens answering *who did what, when* — sourced from audit/event streams. |
| **Admin portal** | Centralized Fabric administration surface for tenant, capacity, domain, and workspace control. |
| **AI governance** | Policies and procedures for developing and applying ML/AI models responsibly (compliance, reproducibility, explainability, monitoring, cataloging). |
| **Capacity** | The compute resources used by all Fabric workloads; can act as an isolation/chargeback boundary. |
| **Canonical metamodel** | The source-agnostic entity model (Item, RoleAssignment, LineageEdge, …) that every connector maps into; basis for zero-reconfig plug-ins. |
| **Catalog Search API** | Fabric REST API to discover catalog item metadata across workspaces (security-trimmed). |
| **CDGC (Informatica)** | Cloud Data Governance & Catalog — Informatica's governance metadata (assets, glossary, classifications, cross-platform lineage); a Governance OneLens connector source. |
| **Center of Excellence (CoE)** | Cross-functional team that aligns governance design with organizational strategy. |
| **Connector (source)** | A module that maps an external platform's governance metadata (Fabric, Databricks, Purview, …) into the shared, `source`-tagged entity model. Implements one stable contract — drop-in, no app/schema change. |
| **Coverage (monitoring lens)** | Governance-monitoring lens measuring the **%** of assets in a layer that meet a standard (e.g., labeled). |
| **DASF** | Databricks AI Security Framework — catalogs 55 AI risks across 12 components of an AI system. |
| **Data Activator** | Native Fabric capability that triggers alerts/actions when data or metrics meet a condition (used for drift alerts). |
| **Data API (Rayfin)** | Auto-generated **GraphQL** endpoints over the entity model, queried via `RayfinClient`. |
| **Data Catalog (Purview)** | Application layer in Purview exposing captured metadata across all sources. |
| **Data clean room** | Secure, privacy-safe environment where multiple parties join first-party data without exposing PII. |
| **Data federation** | Querying data across heterogeneous sources through a virtual layer without ETL/replication. |
| **Data lineage** | Visualization of how data flows and transforms across items/systems. |
| **Data Loss Prevention (DLP)** | Purview policies that automatically detect sensitive data and enable remediation. |
| **Data Map (Purview)** | Purview's scanning engine and metadata store; exposes metadata via Atlas APIs. |
| **Data mesh** | Architectural pattern organizing data ownership around business domains. |
| **Data steward / owner** | Person accountable for defining and enforcing policies for a data domain. |
| **Direct Lake** | Power BI storage mode that queries Delta tables in OneLake directly, with no import/copy. |
| **Domain** | Logical grouping of organizational data (often by business unit) for discoverability and delegated governance. |
| **Drift** | Deviation from an approved baseline. In **governance** monitoring: a config/access change away from the baseline (alertable). In **ML**: degradation as data/conditions change over time. |
| **DTAP** | Development, Test, Acceptance, Production environment separation. |
| **Endorsement** | Promotion or certification of items to signal trustworthy, quality data. |
| **Fabric Apps (preview)** | Microsoft Fabric's managed app platform (the productized Rayfin): TypeScript data models → Fabric SQL DB + GraphQL API + Fabric SSO + static hosting. |
| **Fabric brokered auth / Fabric SSO** | Sign-in with Microsoft Entra ID via Fabric — the only production auth for Fabric Apps. Read access is gated by a fail-closed governance-reader allowlist (not per-row trimming) — see [ARCHITECTURE.md § Security & Governance](../ARCHITECTURE.md#security--governance). |
| **Fabric SQL database** | The relational store auto-generated by Rayfin from the entity model; Governance OneLens's telemetry + config store, served via the GraphQL API. |
| **Fabric User Data Functions** | Server-side functions in Fabric used for app logic and scan orchestration. |
| **Governance observability** | Continuous monitoring of governance across every Fabric layer via four lenses: posture, coverage, activity, drift. |
| **Governance OneLens (OneLens)** | This project — the Fabric-native governance **observability + catalog** app, built on the Rayfin BaaS. |
| **Impact analysis** | View of which downstream items are affected by a change to an item. |
| **Lakehouse** | Fabric item storing Delta tables in OneLake; a scan source and optional companion analytics store (the app's own store is the Fabric SQL database). |
| **Live view (Purview)** | Purview view of Fabric workspaces a consumer has viewer access to. |
| **MCP (Model Context Protocol)** | Protocol for exposing tools/data to AI agents; Rayfin ships `rayfin-mcp` to serve governance data to Copilot/agents. |
| **Metadata scanning / scanner APIs** | Admin REST APIs that extract Fabric item metadata (labels, endorsement, permissions, lineage) for cataloging tools. |
| **Monitoring hub** | Central Fabric location to monitor activities the user is permitted to view. |
| **OneLake catalog** | Centralized Fabric experience to find, explore, govern, and secure data items (Explore, Govern, Secure tabs). |
| **OneLake security** | Engine-agnostic data-plane security (object/OLS, row/RLS, column/CLS) enforced at the OneLake storage layer. |
| **OpenLineage** | Open standard for emitting lineage events; a connector output format for interoperable lineage. |
| **Posture (monitoring lens)** | Governance-monitoring lens answering *is it configured to standard right now* — sourced from config/scanner APIs. |
| **Private Link** | Private network connectivity to Fabric/OneLake; when enabled, the native Govern tab is unavailable. |
| **Purview Information Protection** | Discovery, classification, and protection of data using sensitivity labels. |
| **Rayfin (BaaS)** | [microsoft/rayfin](https://github.com/microsoft/rayfin) — MIT open-source Backend-as-a-Service, productized as **Fabric Apps (preview)**. Define data models with TypeScript decorators; get a Fabric SQL DB, generated GraphQL API, Fabric SSO, and hosting. Governance OneLens's front-facing platform. |
| **RBAC** | Role/resource-based access control — access applied across roles or groups. |
| **Sensitivity label** | A classification tag (from Purview) that travels with data, including on export. |
| **Service principal** | Non-interactive identity used by Governance OneLens scanner jobs to call APIs with least privilege. |
| **SHAP** | SHapley Additive exPlanations — technique to explain which features drove a model's output. |
| **Tag** | Configurable text label applied to items to improve discoverability and filtering. |
| **Unity Catalog** | Databricks' unified governance layer for data and AI assets (analogous role to OneLake catalog + Purview in Fabric). |
| **Workspace** | Container where teams create Fabric items and collaborate; governed via workspace roles. |
| **Workspace role** | Role assigned to users to regulate access to items in a workspace. |
